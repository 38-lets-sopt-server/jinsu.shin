# 사용자 시나리오

## 시나리오1 : 게시판 탐색 → 게시글 확인

사용자가 자유게시판 목록에 진입하여 게시글 피드를 스크롤합니다.

관심 있는 게시글(예: '주 3시간 강의 4번 빠지면 결석 아님?')을 탭하면 게시글 상세 화면으로 이동하여 본문과 댓글을 확인합니다.

공감, 스크랩 등 상호작용 후 뒤로가기로 목록으로 돌아갑니다.

## 시나리오2: 세 게시글 작성

사용자가 자유게시판 목록 하단의 글쓰기 FAB 버튼을 탭합니다.

글 쓰기 화면이 모달로 열리며, 제목과 본문을 입력합니다.

익명 여부를 선택하고 완료 버튼을 탭하여 게시글을 등록합니다.

등록 완료 후 자유 게시판 목록으로 돌아가며, 세 게시글이 상단에 표시됩니다.

## 시나리오3: 댓글 작성 및 대댓글

게시글 상세 화면에서 하단 댓글 입력창에 텍스트를 입력합니다.

익명 체크박스를 확인 후 전송 버튼을 탭하여 댓글을 등록합니다.

기존 댓글에 대댓글을 달 수 있으며, 대댓글은 들여쓰기로 구분됩니다.
