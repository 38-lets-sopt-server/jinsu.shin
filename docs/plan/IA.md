# IA

## 자유게시판 목록

- 상단 네비게이션 바
- 광고 배너 (외부 광고)
- 고정/추천 게시글 카드
- 인기 게시글 (Hot) 바
- 게시글 피드 (스크롤)
    - ㄴ 제목 / 미리보기 / 메타
- FAB '글 쓰기' 버튼

---

## 게시글 상세

- 상단 네비게이션 바
- 작성자 정보 (아바타/닉네임/시간)
- 게시글 본문 (제목 + 내용)
- 액션바 (공감/댓글/스크랩)
- 광고 배너
- 댓글 목록 (스크롤)
    - ㄴ 댓글 (아바타/닉네임/내용)
    - ㄴ 대댓글 (들여쓰기, ㄴ 표시)
- 하단 댓글 입력바 (익명/입력/전송)

---

## 글 쓰기

- 상단 바 (X 닫기 / 완료)
- 제목 입력 필드
- 본문 입력 필드
- 커뮤니티 이용규칙 안내
    - ㄴ 규칙 전체 보기 링크
    - ㄴ 규칙 요약 텍스트
- 하단 툴바
    - ㄴ 카메라 / 링크 첨부
    - ㄴ 질문 토글 / 익명 토글
