# 게시글 상세

## ① 상태 바 (Status Bar)

- **기능**: 시스템 상태 정보 표시 (시간 3:38, 네트워크 5G, 배터리 91%). OS 제어 영역.
- **인터랙션**: 없음. 사용자 조작 불가 영역.

## ② 네비게이션 바 (Nav Bar)

- **구성**: 좌측 '<' 뒤로가기, 중앙 '자유게시판'+'인하대', 우측 알림끄기(🔔)+더보기(:)
- **인터랙션**: '<' 탭: 목록(1.1)으로 이동. 🔔 탭: 해당 게시글 알림 on/off 토글. ':' 탭: 신고/삭제/공유 옵션 메뉴.
- **이동 화면**: < → 자유게시판 목록(1.1) | : → 신고/삭제/공유 액션시트

## ③ 작성자 정보 (Author Info)

- **구성**: 회색 아바타 + '익명' 닉네임(굵은 글씨) + '03/27 15:22' 타임스탬프(회색).
- **인터랙션**: 익명 게시판이므로 실명 비공개. 프로필 탭 불가.

## ④ 게시글 본문 (Post Content)

- **구성**: 제목 "주 3시간 강의 4번 빠지면 결석 아님?"(18px, Bold) + 본문 "맞지?"(15px). 이미지 첨부 시 본문 하단 표시.
- **인터랙션**: 텍스트 선택/복사 가능. 이미지 탭 시 전체화면 보기.

## ⑤ 액션 바 (Action Bar)

- **구성**: 👍 공감 | 💬 댓글 3 | ⭐ 스크랩. 세 가지 버튼 가로 균등 배치.
- **인터랙션**: 공감 탭: +1/취소 토글. 댓글 탭: 댓글 영역으로 스크롤. 스크랩 탭: 내 스크랩 목록에 저장/해제.
- **상태**: 공감/스크랩 활성 시 아이콘 색상 변경(빨강/노란), 비활성: 회색.

## ⑥ 광고 배너 (Ad Banner)

- **기능**: Spotify 학생 할인 광고. 녹색(#1DB954) 배경 + 텍스트 + 핸드폰 이미지.
- **인터랙션**: 탭: 외부 Spotify 페이지로 이동. 닫기(x) 버튼으로 광고 숨김 기능.

## ⑦ 댓글 목록 (Comments)

- **구성**: 각 댓글: 아바타 + 닉네임(익명1/익명2) + 본문 + 타임스탬프. 우측 👍/ : 아이콘.
- **인터랙션**: 👍 탭: 댓글 공감. ':' 탭: 신고/삭제. 길게 누르기: 복사/답글 옵션. 세로 스크롤 가능.

## ⑧ 대댓글 (Reply)

- **구성**: 'ㄴ' 아이콘으로 들여쓰기 표시. 부모 댓글 하위에 위치. 형식은 일반 댓글과 동일.
- **인터랙션**: 대댓글의 대댓글은 같은 레벨에 표시. 공감/신고 동일하게 적용.

## ⑨ 하단 댓글 입력 바

- **기능**: 댓글 및 대댓글 작성을 위한 고정 하단 입력 바
- **구성**: 텍스트 입력 필드 (placeholder: '댓글을 입력하세요') + 익명 체크박스 + 전송 버튼
- **인터랙션**: 입력 필드 탭 → 키보드 올라옴, 텍스트 입력 후 전송 버튼 탭 → 댓글 등록 및 목록에 추가. 익명 체크 시 '익명'으로 표시
- **상태**: 비어있을 때 전송 버튼 비활성화 (회색), 텍스트 입력 시 전송 버튼 활성화 (빨간색)
- **이동 화면**: 없음 (현재 화면에서 댓글 추가 후 목록 갱신)
